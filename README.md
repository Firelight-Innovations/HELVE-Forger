# Helve Forger

Technical design software for the Helve stack. Used to spec out the whole
stack and define boundaries between pieces, including visually. Forger
predates Engine — Engine gets built using Forger, then Forger continues
designing everything after.

This is a development tool; it does not ship with games built on Helve.

Status: pre-alpha, scaffolding only. Tech stack TBD.

Part of the [Helve](https://github.com/Firelight-Innovations/helve) stack.
